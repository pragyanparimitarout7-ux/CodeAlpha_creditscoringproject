# Credit Scoring Model — Project Report

## Objective
Predict an applicant's credit class from financial and credit-history features.

## Method
The dataset is split into training/testing sets. Logistic Regression, Decision Tree and Random Forest are trained and compared.

## Metrics
Accuracy, Precision, Recall, F1 Score and ROC-AUC. The project also generates a confusion matrix, ROC curve and Random Forest feature-importance chart.

## Interactive component
Users can enter applicant information in the terminal or use the Streamlit web interface to receive a predicted credit class and probability.

## Limitation
This is a synthetic educational dataset and must not be used for real lending decisions.
