# Credit Scoring Model — CodeAlpha Task 1

Complete machine-learning project with Logistic Regression, Decision Tree and Random Forest.

## Run
```bash
pip install -r requirements.txt
python credit_scoring.py
```

The Python program trains/evaluates models, creates graphs, and asks for applicant details for an interactive prediction.

## Web app
```bash
streamlit run app.py
```

Extras: model comparison, confusion matrix, ROC curve, Random Forest feature importance, terminal prediction and Streamlit interface.

The included dataset is synthetic and intended for educational use only.
